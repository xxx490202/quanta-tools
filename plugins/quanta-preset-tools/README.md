# quanta-preset-tools

Quanta's dsh plugin for narrowing the tool list of a subagent. It calls `ctx.tools.restrict({ allow })` inside the subagent's preset scope, so the child only sees the tools Quanta allows.

This package is generated by the Quanta app at startup (see `PRESET_TOOLS_PLUGIN_PKG` / `PRESET_TOOLS_PLUGIN_JS` in `dsh_agent.py`) and installed into the dsh ACP profile. The copy here is for reference and reuse; editing it does not change the app-generated copy.

## Files

- `package.json`
- `lib/index.js`

## Notes

Requires a dsh runtime that exposes `ctx.tools.restrict`.
