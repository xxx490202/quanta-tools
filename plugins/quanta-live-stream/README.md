# quanta-live-stream

Quanta's dsh ACP plugin. It streams reasoning deltas, agent status, background-job events, and context-compaction events to stderr so the Quanta UI can render them live.

This package is generated by the Quanta app at startup (see `LIVE_PLUGIN_PKG` / `LIVE_PLUGIN_JS` in `dsh_agent.py`) and installed into the dsh ACP profile. The copy here is for reference and reuse; editing it does not change the app-generated copy.

## Files

- `package.json`
- `lib/index.js`

## Notes

Requires a dsh runtime that exposes `ctx.jobs` and the `agent/assistant-stream` / `agent/status` events.
